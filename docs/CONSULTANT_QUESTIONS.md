# Registro de resolución — Catálogo de cálculo

> **Estado:** cerrado el 19 de agosto de 2026. Este archivo conserva la
> trazabilidad de las preguntas originales; las reglas autoritativas están en
> `docs/CALCULATION_CATALOG.md`.

| Tema original | Resolución |
|---|---|
| CSAT — denominador | 4–5 forman el numerador; todas las respuestas válidas 1–5 forman el denominador. Desconocimiento/No aplica se excluye. Se calcula por punto de contacto; no hay CSAT general. |
| CRI — agregación | Promedio ponderado: Nada=100, Poco=75, Algo=50, Muy=25, Extremadamente=0. El resultado es riesgo directo. |
| NPS — escala | La encuesta de Be Community usa 1–10: detractores 1–6, pasivos 7–8, promotores 9–10. |
| NPS — pasivos | No aportan al numerador, pero permanecen en el total válido usado por ambos porcentajes. El tablero histórico confirma esta interpretación. |
| Limpieza | El proceso actual fue documentado mediante recorridos de las bases reales. Las reglas específicas se implementarán en adaptadores de ingesta, no como una fórmula global. |
| LTV | Es un valor por persona proporcionado por la organización; no se calcula en Be Community. Se usa para cruces configurados. |
| Power Pivot | Quedó como fuente de auditoría opcional. No sustituye correcciones metodológicas posteriores ni bloquea el catálogo. |

También quedaron confirmados TDP, retención, deserción y redondeo. Los asuntos
de muestra mínima, privacidad, duplicados, formatos visuales y referentes por
sector son políticas de producto/ingeniería y no requieren otra ronda de
preguntas metodológicas.
